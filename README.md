# Glow & Shine

Application de réservation pour Glow & Shine.

## Installation
1. Installer Node.js.
2. Dans ce dossier : `npm install`
3. Copier `.env.example` vers `.env`
4. Mettre le vrai lien Wave dans `VITE_WAVE_PAYMENT_URL`.
5. Lancer : `npm run dev`

## Déploiement
Le projet est prêt à être importé dans GitHub puis connecté à Vercel.

Supabase utilisé : projet `Glow-and-Shine` (`aneehtejwszqszkqzump`).
